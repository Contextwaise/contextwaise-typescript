# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/Contextwaise/contextwaise-typescript/security/advisories/new),
or email **support@contextwaise.com** with "Security" in the subject.

Include what you found, how to reproduce it, and the SDK version. We reply within
3 business days and keep you updated until it is fixed. We credit reporters in the
release notes unless you'd rather stay anonymous.

## Supported versions

Fixes go into the latest release. Please upgrade before reporting.

## Scope

This repository is the TypeScript SDK, which runs in your process. Issues with the hosted
Contextwaise API or dashboard are in scope too: report them the same way.
